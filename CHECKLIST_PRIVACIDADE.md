# Checklist de Privacidade - Kids_Play

## Consentimento
- [ ] Consentimento separado por finalidade
- [ ] Padrão desligado para dados opcionais
- [ ] Histórico de consentimentos registrado
- [ ] Possibilidade de revogação

## Direitos do Titular
- [ ] Exportação de dados (JSON/CSV)
- [ ] Exclusão de criança com anonimização
- [ ] Exclusão de conta
- [ ] Confirmação em duas etapas

## Segurança
- [ ] RLS em todas as tabelas
- [ ] URLs assinadas para Storage (curta duração)
- [ ] Sem chaves secretas no frontend
- [ ] Sem coleta de dados de saúde
- [ ] Sem terceiros para marketing/analytics

## Transparência
- [ ] Páginas legais em revisão
- [ ] Avisos claros e linguagem simples
- [ ] Sem coleta de localização/microfone/câmera
