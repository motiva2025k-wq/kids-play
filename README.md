# Kids_Play

App educacional gamificado com foco em acessibilidade, TDAH-friendly e motivação positiva.

## Tecnologias
- Vite + React + JavaScript/JSX
- Supabase (Auth, DB, RLS, Storage, Edge Functions, RPC)
- Tailwind CSS (tema customizado)
- Kapivarus (personagem tutor)

## Fases implementadas
- Fase 1–3: Auth, Perfis, Motor de Missões, Feedback gentil
- Fase 4: XP, Níveis (1–20), Streak com escudo de folga, Medalhas
- Fase 5: Ranking (Semanal/Mensal/Global), Ligas, Pódio, Hall da Fama, Troféus de Esforço
- Fase 6: Loja + Inventário + Equipar itens
- Fase 7: Notificações gentis (Toasts) + Celebrações
- Fase 8: Relatórios para Responsáveis (foco em esforço)
- Fase 9: Refinamentos + QA + E2E
